## 使用说明

### 完整流程（默认逐阶段确认）
```
/just-fe  需求文档内容...
```

### 不设闸门连续跑
```
/just-fe --auto 需求文档内容...
```

### 续接指定阶段
```
/just-fe --from=⑤ --需求="商品详情页"
/just-fe --from=⑥
```

### 恢复中断
```
/just-fe --resume
```
